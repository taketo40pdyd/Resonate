    Resonate EQ について

    Resonate EQ は、インストール不要でブラウザからそのまま使えるグラフィックイコライザーです。手持ちの音声ファイルを開いて、再生しながら低音から高音までの音質を自由に調整できます。

    主な機能

    • 5・10・15・20・31バンドから選べるグラフィックイコライザー。各バンドは±12 dBで調整でき、ノブで帯域幅（Q）も変えられます
    • Rock・Pop・Jazz・Vocal・Gaming などのプリセットと、VLC標準プリセットを収録
    • クリアリティ・アンビエンス・サラウンドサウンド・ダイナミックブースト・ベースブーストの5つのサウンド効果
    • 音声ファイルの波形を見ながら調整
    • MIDIコントローラーのフェーダーやつまみでEQを操作（MIDIラーニング対応）。メディアキー・ヘッドセットのボタンをプリセット切り替えなどに割り当て可能
    • グラフ上をなぞってEQカーブを直接描ける描画モード。バンドごとのミュート（補正を外す）とソロ（その帯域だけを試聴）
    • 再生位置の表示とシークバー（ドラッグ、キーボード、ロック画面の操作に対応）
    • 曲名・アーティスト・アルバム・ジャケット画像（タグ）の表示。ロック画面や通知の再生コントロールにも反映（MP3・M4A・FLAC・Ogg/Opusに対応）
    • 2つの設定を瞬時に切り替えて聴き比べられるA/B比較（音量を揃える機能つき）
    • 曲ごとにプリセットを紐づけて、再生に合わせて自動で切り替え。低音・ボーカル・高音をワンタッチで強調
    • 周波数ごとの音量を表示するスペクトラムアナライザー（波形との切り替え、重ね表示に対応）
    • 複数のファイルを再生リストにして連続再生（前後の曲・リピート・シャッフルに対応）
    • ハイレゾ向けに、処理サンプルレートを48〜192 kHzから選択可能
    • 設定に名前を付けて「マイプリセット」に複数保存でき（上書き・名前変更・並べ替え・削除に対応）、JSONファイルでインポート／エクスポート可能
    • 起動音と操作音（設定でオフ・音量調整可）
    • なめらか編集（隣の帯域も連動して動かす）
    • イコライザー操作の元に戻す／やり直し（最大100段階）
    • A-Bループ再生（曲の一部区間を繰り返し再生）
    • 再生速度の変更（0.5〜2倍）
    • スリープタイマー（指定時間、曲の終わり、または数曲後に自動停止）
    • お気に入り（★）の登録と、お気に入りだけの表示
    • インストールしてオフラインでも利用でき、キーボードショートカットにも対応

    よくある質問

    音声ファイルはアップロードされますか？

    いいえ。読み込んだ音声はお使いの端末のブラウザ内だけで処理され、外部のサーバーには送信されません。

    どのブラウザで使えますか？

    Web Audio API に対応した最新のブラウザで動作します。出力デバイスの切り替えは Chrome / Edge のみ対応です。

    オフラインでも使えますか？

    アプリとしてインストール（ホーム画面に追加）すると、オフラインでも使えます。

    設定はどこに保存されますか？

    マイプリセットやオーディオ設定は、この端末のブラウザ内に保存されます。ブラウザのデータを消去すると失われるため、大切なプリセットはエクスポートでバックアップしてください。

    設定

    オーディオ


    サウンド

    効果音は音楽とは別に再生され、イコライザーの影響を受けません。ブラウザの仕様上、起動音はページを最初に操作したときに鳴ります。

    マイプリセット


      いまのイコライザーとサウンド効果の設定に名前を付けて、最大40件まで保存できます。「上書き」で内容を更新、「名前変更」「↑↓」「削除」で整理できます。インポートした設定も新しいマイプリセットとして追加されます（バンド数が違うファイルは自動で補間します。複数まとめて書き出したファイルも読み込めます）。

      再生

      速度を変えると音の高さも変わります（テープの回転数を変える感覚です）。

      フェードインは再生を始めるとき、フェードアウトは曲の終わりに働きます。クロスフェードを使うと、曲の終わりと次の曲の始まりが重なります（このときフェードアウトは使いません）。1曲リピート、A-Bループ中、処理サンプルレートが曲ごとに変わる場合は、クロスフェードせずに次の曲へ進みます。一時停止ボタンやSpaceキーでの一時停止には、最大2秒のフェードアウトがかかります（フェード中にもう一度押すと再生を続けます）。シークや停止ボタンにはかかりません。

      曲を止めた位置を、ファイル名・サイズ・更新日時で覚えます。同じファイルをもう一度開くと、その位置から再生します（複数選んだときは、最後に聴いていた曲から始まります）。ファイル本体は保存しないので、ページを開き直したあとはファイルを選び直してください。

      イコライザー補助

        イコライザー画面の「この曲に紐づけ」で、いまのプリセットを再生中の曲に結び付けられます。紐づけた曲を再生すると自動でそのプリセットに切り替わり、紐づけのない曲に移ると元のプリセットへ戻ります（A/B比較中は切り替えません）。曲はファイル名・サイズ・更新日時で見分けるので、同じファイルを開き直しても有効です。カスタムの設定は、マイプリセットに保存してから紐づけてください。ワンタッチ強調は、いまの設定に低音・ボーカル・高音の補正を重ねるボタンです。もう一度押すと元の設定に戻り、ほかの操作をするとその時点の設定が残ります。

        ハイレゾ

        WAV・FLACは元のレートと量子化ビット数を読み取ります。端末の出力が対応していない場合は、最後に端末のレートへ変換されます。

        96 kHz以上に引き上げ、元の音の高域から16 kHz以上の成分を作って足します。元データにない成分を推定して加える処理なので、もともとのハイレゾ音源と同じものにはなりません。

        16 bitでは、ざらつきを抑えるディザ処理を自動で入れます。32 bit 浮動小数点は、書き出したあとにDAWなどで編集する場合向けです（ファイルが大きくなります）。現在のイコライザー・サウンド効果・音量・バランス・ハイレゾ化の設定を反映して保存します。再生速度は反映されず、元の速さで書き出します。サンプルレートは処理中のレートと同じです。

        マイプリセットの「共有」を押すと、そのプリセットのリンクをコピーできます。スライダーはダブルクリックで初期値に戻ります。優先出力の変更は対応ブラウザ（Chrome / Edge）のみです。

        インターネットラジオ

          局のURLを直接入力して追加

          mp3・AACなどの音声ストリームのURL（IcecastやSHOUTcastなど）を指定できます。追加した局はお気に入りに入ります。.m3u8（HLS）や、.pls・.m3uなどの再生リストは使えません。ここでも、配信側が他のサイトからの利用（CORS）を許可している必要があります。

          局の一覧は Radio Browser（コミュニティが運営する公開データベース）から取得します。HTTPS配信の局だけを表示します。EQを通すには、配信側が他のサイトからの利用（CORS）を許可している必要があるため、再生できない局もあります。その場合は別の局をお試しください。

                データの管理

                「クラウドのデータを削除」はクラウド上の保存内容だけを消してログアウトします。「アカウントを削除」はクラウドのデータとアカウントの両方を消します。どちらも、この端末に保存されている設定やプリセットは消えません。

                メールアドレス、またはGoogleアカウントでログインできます。ログインすると、オーディオ設定、マイプリセット、曲ごとのプリセット紐づけがクラウドに保存され、別の端末でも同じ内容を使えます。変更は自動で同期されます（出力デバイスの選択は端末ごとの設定のため同期しません）。再生リストや曲のデータは保存されません。

                コントローラー

                MIDI

                  バンドのゲインは、先頭のCC番号から順に、低い周波数のバンドから割り当てます（例：先頭が21で10バンドなら CC21〜30）。ほかの項目は「学習」を押してから、割り当てたいつまみ・フェーダー・ボタンを動かすと登録されます（つまみ類はCC、ボタン類はCCまたはノートに対応）。ボタンはCCの値が64以上になった瞬間に働きます。MIDIはChrome / Edgeなどが対応しています（Safariは非対応）。

                  メディアキー・ヘッドセット

                  キーボードのメディアキー、ヘッドセットのボタン、ロック画面の操作に反映されます。ブラウザによっては、音声を再生している間だけキーが届きます。再生／一時停止キーは常に再生／一時停止です。

                  サポート

                  使い方

                  赤い点を上下にドラッグすると各周波数帯のゲイン（±12 dB）、下のノブを上下にドラッグすると帯域幅（Q）を変えられます。ノブはダブルタップで初期値に戻ります。「ファイルを開く」で手持ちの音声を読み込めます。

                  「カーブを描く」をオンにすると、グラフ上をなぞって直接カーブを描けます。ノブの下の M はその帯域の補正を一時的に外し（ミュート）、S はその帯域だけを聴きます（ソロ）。
